# UTEK Senior Design 2026

Team: Atharv, Akash, Jadyn, and Matteo.

Shared workspace for competition firmware, build notes, testing, and final deliverables. The challenge has not been released; this repository contains organizational scaffolding only.

## Layout

- `firmware/`: ESP32 source code and dependency instructions.
- `docs/`: requirements, pin assignments, wiring, decisions, and references.
- `tests/`: calibration and test results.
- `media/`: prototype photos and diagrams.
- `submission/`: copies of the final submitted deliverables.

## Working together

1. Clone this repository and pull before starting work.
2. Coordinate file ownership before editing. Use short branches for changes that could disrupt a working prototype.
3. Commit small, descriptive changes and push regularly.
4. Keep one person responsible for firmware integration and the board upload.
5. Record board model, tool versions, libraries, wiring, and how to reproduce the build.
6. Preserve a known-working commit before making risky changes.
7. Keep credentials, generated build files, and personal information out of the repository.

Confirm the competition rules for prepared material, external code, and AI before using any of these during the event. Reference all external sources used.
